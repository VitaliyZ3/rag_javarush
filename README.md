# RAG — Нормативна база РТЗ

Простий локальний помічник, який вміє відповідати на питання по нормативних документах (реєстрація транспортних засобів). Ти завантажуєш свої документи (Word, Excel, PDF, markdown), система їх "запам'ятовує", а потім можна ставити питання звичайною мовою — і отримувати відповідь із посиланням на те, звідки вона взята.

Все працює локально, на власному комп'ютері, без відправки документів у хмару.

## Що потрібно встановити (один раз)

1. **Python 3.12+**
2. **uv** — менеджер залежностей ([інструкція](https://docs.astral.sh/uv/getting-started/installation/))
3. **Ollama** — програма, яка запускає мовну модель локально ([ollama.com](https://ollama.com/download))

Після встановлення Ollama, завантаж модель (один раз, ~1.6 ГБ):

```
ollama pull gemma2:2b
```

Потім встанови залежності проєкту:

```
uv sync
```

## Як запустити

1. Переконайся, що Ollama працює (зазвичай запускається сама як фонова служба; якщо ні — виконай `ollama serve` в окремому терміналі).
2. Запусти застосунок:

```
streamlit run app.py
```

3. У браузері автоматично відкриється сторінка (або перейди на `http://localhost:8501`).

## Як почати працювати зі своїми документами

1. Поклади файли документів у папку `data/raw/`. Підтримуються формати: `.docx`, `.xlsx`/`.xls`, `.pdf`, `.md`.
2. Заверши цикл — команда "прочитає" документи і побудує пошуковий індекс:

```
python ingest.py
```

3. Це все — можна ставити питання в застосунку.

**Що важливо знати:**
- Ця команда безпечна для повторного запуску: якщо документ не змінився — він просто пропускається, нічого заново не перераховується.
- Якщо додав новий файл або відредагував існуючий — просто запусти `python ingest.py` знову, воно саме розбереться, що нове/змінене.
- Якщо видалив файл з `data/raw/` — після наступного запуску `ingest.py` він також зникне з пошуку.

## Як користуватись

1. Відкрий застосунок у браузері.
2. Введи питання в текстове поле (або натисни один з готових прикладів справа).
3. Натисни «🚀 Знайти відповідь».
4. Отримаєш відповідь, кількість знайдених фрагментів тексту та назви документів-джерел.

## Типові проблеми

**"Не вдалося отримати відповідь... Перевір, що Ollama запущена"**
→ Ollama не працює. Відкрий термінал і виконай `ollama serve`, залиш його відкритим, онови сторінку застосунку.

**Відповідь "Не знайдено в документах"**
→ Або в `data/raw/` немає потрібного документа, або по ньому ще не запускали `python ingest.py`.

**Хочу змінити модель або кількість документів, які переглядає система**
→ Скопіюй `.env.example` у `.env` і зміни значення там (файл із поясненнями кожного параметра).
