# RAG — нормативна база реєстрації транспортних засобів

Проєкт дає змогу ставити запитання українською мовою до локального набору нормативних документів. Система знаходить релевантні фрагменти документів і формує відповідь на їх основі.

## Технології

- **Python 3.12+** та **uv** — середовище й залежності проєкту.
- **Streamlit** — вебінтерфейс.
- **LangChain** — інтеграція завантаження документів, пошуку, промпту та мовної моделі.
- **ChromaDB** — локальне векторне сховище.
- **Hugging Face Sentence Transformers** — локальні embeddings; модель за замовчуванням `paraphrase-multilingual-MiniLM-L12-v2`.
- **BM25 + векторний пошук** — гібридне знаходження фрагментів: BM25 допомагає з точними термінами й кодами, векторний пошук — із семантичними запитами.
- **Ollama** — локальний LLM; модель за замовчуванням `gemma2:2b`.

## Передумови

1. Python 3.12 або новіший.
2. [uv](https://docs.astral.sh/uv/).
3. [Ollama](https://ollama.com/) із завантаженою моделлю, що відповідає `LLM_MODEL`.

## Запуск локально

У корені репозиторію:

```bash
uv sync --group dev
cp .env.example .env
```

`.env` необов'язковий: усі параметри мають значення за замовчуванням у `rag_verify/config.py`. За потреби змініть їх у `.env`.

Завантажте модель Ollama за замовчуванням і запустіть Ollama (якщо сервіс ще не працює):

```bash
ollama pull gemma2:2b
ollama serve
```

Додайте документи до `data/raw/` і побудуйте або оновіть індекс:

```bash
uv run python ingest.py
```

Запустіть вебзастосунок:

```bash
uv run streamlit run app.py
```

Streamlit покаже локальну адресу застосунку в терміналі. Уведіть запитання або виберіть приклад у другій колонці основної сторінки.

## Як користуватися

1. Покладіть файли нормативних документів у `data/raw/`.
2. Запустіть `uv run python ingest.py`, щоб додати їх до індексу.
3. Запустіть застосунок і поставте запитання українською.
4. Перегляньте відповідь, кількість знайдених фрагментів і назви джерел.

Підтримуються PDF, DOCX, XLS/XLSX і Markdown (`.md`). Індексація інкрементальна: незмінені файли пропускаються, змінені переіндексовуються, а для видалених файлів записи прибираються з індексу. Повторний запуск `ingest.py` після додавання або зміни документів достатній для оновлення бази.

## Як це працює

1. **Індексація:** завантажувачі читають документи з `data/raw/`, splitter ділить текст на фрагменти, Hugging Face-модель обчислює embeddings, а Chroma зберігає фрагменти та embeddings локально.
2. **Маніфест:** `data/processed/manifest.json` зберігає хеші джерел, текст фрагментів, metadata і стабільні ID. Він дає змогу визначати зміни між запусками та є джерелом фрагментів для BM25.
3. **Пошук:** BM25 і Chroma послідовно виконують окремі пошуки; результати об'єднуються зваженим reciprocal-rank fusion. Якщо маніфест ще не містить фрагментів, використовується векторний пошук.
4. **Відповідь:** `RagPipeline` бере не більше `RETRIEVAL_K` фрагментів, додає їх до промпту й передає локальній Ollama-моделі. Промпт вимагає відповідати українською лише на основі контексту; якщо відповіді в ньому немає, модель має повідомити, що її не знайдено в документах.

Основний потік запиту зібраний у `rag_verify/pipeline.py`; індексація — у `rag_verify/ingestion/`; пошук — у `rag_verify/retrieval/`; конфігурація та фабрики LLM/промпту — у `rag_verify/config.py` і `rag_verify/generation/`. `app.py` є Streamlit-клієнтом, `ingest.py` — CLI для індексації.

## Налаштування

Параметри та значення за замовчуванням наведені в `.env.example` і `rag_verify/config.py`:

| Змінна | Значення за замовчуванням | Призначення |
| --- | --- | --- |
| `EMBED_MODEL` | `paraphrase-multilingual-MiniLM-L12-v2` | Модель embeddings |
| `EMBED_DEVICE` | `cpu` | Пристрій для embeddings |
| `LLM_MODEL` | `gemma2:2b` | Назва моделі в Ollama |
| `LLM_TEMPERATURE` | `0.1` | Температура генерації |
| `LLM_NUM_CTX` | `2048` | Розмір контексту моделі |
| `LLM_NUM_PREDICT` | `512` | Максимум токенів відповіді |
| `CHUNK_SIZE` | `500` | Розмір фрагмента |
| `CHUNK_OVERLAP` | `50` | Перекриття фрагментів |
| `RETRIEVAL_K` | `6` | Кількість фрагментів для відповіді |
| `BM25_WEIGHT` | `0.4` | Вага BM25 у гібридному пошуку |

## Тести

```bash
uv run pytest
```

Запустити окремий тест:

```bash
uv run pytest tests/test_ingestion.py::test_new_file_gets_indexed
```

Наявні тести перевіряють інкрементальну індексацію та використовують заглушку замість Chroma, тому для них не потрібно запускати Ollama чи завантажувати модель embeddings.
